# SecureIT Pro — Incident Registration Portal

Учебное Node.js-приложение для регистрации инцидентов информационной безопасности.

## Запуск

```bash
npm install
npm start
```

Затем открыть:

```text
http://localhost:3000
```

## Что реализовано

- форма регистрации инцидента;
- обязательные поля `Incident Title`, `Reporter`, `System`, `Severity`;
- валидация длины и формата;
- disabled-состояние кнопки `Report Incident`;
- динамический `id` у кнопки отправки, например `btn_report_12345`;
- асинхронное появление формы, таблицы и сообщения;
- асинхронное обновление таблицы;
- автоинкремент ID;
- добавление новой записи в конец таблицы;
- тестовые данные;
- повторяющиеся строки таблицы для тренировки XPath;
- уникальные `id` у основных элементов интерфейса.
