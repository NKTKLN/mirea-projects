# SecureIT Pro — Incident Registration Portal v2

Учебное Node.js-приложение для регистрации и обработки инцидентов информационной безопасности.

## Запуск

```bash
npm install
npm start
```

Открыть:

```text
http://localhost:3000
```

## Реализовано

### Регистрация инцидента

- форма регистрации инцидента;
- обязательные поля `Incident Title`, `Reporter`, `System`, `Severity`;
- валидация длины и формата;
- disabled-состояние кнопки `Report Incident`;
- динамический `id` у кнопки отправки, например `btn_report_12345`;
- асинхронное появление формы, таблицы и сообщения;
- автоинкремент ID;
- добавление новой записи в конец таблицы;
- тестовые данные.

### Управление статусами

- выбор строки таблицы;
- кнопка `Start Investigation`;
- кнопка `Close Incident`;
- логика переходов:
  - `Reported` → `Investigating`;
  - `Reported` / `Investigating` → `Resolved`;
- `Start Investigation` активна только для `Reported`;
- `Close Incident` активна для всех статусов, кроме `Resolved`;
- обе кнопки disabled, если строка не выбрана;
- задержка обновления таблицы и имитация `Loading...`.

### Фильтрация и поиск

- `Filter by Severity`: `All`, `Low`, `Medium`, `High`, `Critical`;
- фильтрация без перезагрузки страницы;
- `Search by Title` в реальном времени;
- частичное совпадение по названию;
- сообщение `No incidents found`, если данных нет.

### Для RPA-тестирования

- уникальные `id` у элементов интерфейса;
- динамический `id` у кнопки отправки;
- повторяющиеся строки таблицы;
- асинхронные задержки;
- состояния `disabled`;
- выбор строк и обновление DOM.
