# **Политика конфиденциальности Sudoku App**

Дата обновления: **21.11.2025**

Настоящая Политика конфиденциальности описывает, какие данные собирает мобильное приложение **Sudoku App**, как они используются, хранятся и защищаются.
Используя приложение, вы соглашаетесь с условиями данной Политики.

## 1. Какие данные мы собираем

Приложение **не собирает и не обрабатывает персональные данные**, такие как адрес электронной почты, номер телефона, фотографии, геолокация или платежная информация.

Единственный тип данных, который может быть сохранён:

### 1.1. Данные для онлайн-лидерборда

При игре в режиме «На рекорд» приложение отправляет на сервер MockAPI.io следующие сведения:

* Имя игрока (текст, введённый вручную)
* Время прохождения (в секундах)
* Уровень сложности (например, Medium)

Эти данные не позволяют идентифицировать конкретного человека и используются исключительно для отображения публичной таблицы рекордов.

### 1.2. Технические данные

Приложение **не** собирает данные об устройстве, не использует файлы cookie, не применяет аналитические или рекламные SDK.

## 2. Как используются данные

Переданные данные используются только для:

* отображения списка рекордов внутри приложения,
* формирования рейтинга игроков.

Никаких других целей использования данных нет.

## 3. Обмен и передача данных третьим лицам

Мы **не передаём**, **не продаём** и **не распространяем** данные пользователя третьим лицам, рекламным сетям, аналитическим сервисам или внешним компаниям.

Единственное внешнее хранилище — это выбранный сервис MockAPI.io, куда отправляются результаты игр. Эти данные публичны в рамках таблицы рекордов.

## 4. Хранение и защита данных

Данные хранятся на серверах MockAPI.io и защищены их стандартными средствами безопасности.

Мы не храним данные на собственных серверах и не сохраняем их на устройстве пользователя (кроме обычного кэширования приложения).

## 5. Удаление данных

Любой пользователь может запросить удаление своих данных (имени и результата игры).
Для этого необходимо связаться по электронной почте:

**[nktkln@nktkln.com](mailto:nktkln@nktkln.com)**

В запросе укажите:

* имя, использованное в игре,
* ориентировочное время результата.

Мы удалим запись из базы MockAPI.io.

## 6. Дети

Приложение можно использовать без регистрации и не собирается персональная информация, позволяющая идентифицировать ребёнка.
Sudoku App соответствует требованиям COPPA / GDPR-KID.

## 7. Ссылки на сторонние ресурсы

Приложение не содержит внешних ссылок, рекламы или переходов в сторонние приложения.

## 8. Изменения Политики

Мы можем обновлять Политику конфиденциальности при необходимости.
Дата актуальной версии всегда указана в верхней части документа.

Продолжение использования приложения означает согласие с обновлённой политикой.
