## English Version

Firewalls, antivirus programs, and encryption are key tools to protect digital systems. A firewall controls data that enters or leaves a network. It checks data packets using filters set by users. Filters can block certain websites, IP addresses, or words. If a program is blocked but needed, a user can allow it through manually without weakening the firewall. 

Antivirus software finds and removes harmful programs like viruses, worms, and Trojans. It may also remove unwanted software like spyware and adware. It works by recognizing a virus’s unique “signature” or behavior. Some antivirus tools ask before acting, others do it automatically. They use two methods: signature scanning checks against known malware, and heuristic scanning looks for suspicious behavior to detect new threats. 

Encryption protects data by turning readable text into coded text called ciphertext. Only those with the key can turn it back into readable text. There are two types: symmetric, where the same key is shared, and asymmetric, which uses a public key to encrypt and a private key to decrypt. Encryption ensures that messages are confidential, unchanged, and verified. Attacks on encryption include brute force, which guesses keys, and cryptanalysis, which finds flaws in the code. The longer the key, the harder it is to break. These tools — firewall, antivirus, and encryption — work together to keep systems secure. Understanding their roles helps users stay protected from online threats in a simple, reliable way.

## Russian Version

Брандмауэры, антивирусные программы и шифрование — это основные инструменты для защиты цифровых систем. Брандмауэр контролирует данные, которые входят в сеть или выходят из неё. Он проверяет пакеты данных с помощью фильтров, заданных пользователем. Фильтры могут блокировать определённые сайты, IP-адреса или слова. Если какая-то программа заблокирована, но нужна, пользователь может разрешить ей доступ вручную, не ослабляя защиту всей системы. 

Антивирусное ПО обнаруживает и удаляет вредоносные программы, такие как вирусы, черви и трояны. Оно также может удалять нежелательное ПО, например шпионские или рекламные программы. Антивирус работает, распознавая уникальный «подпись» вируса или его поведение. Некоторые программы спрашивают разрешение на удаление, другие делают это автоматически. Используются два метода: сигнатурное сканирование — сравнение с базой известных угроз, и эвристический анализ — поиск подозрительных действий для выявления новых вирусов. 

Шифрование защищает данные, превращая читаемый текст в зашифрованный — шифртекст. Расшифровать его можно только при наличии ключа. Бывает симметричное шифрование — с общим ключом, и асимметричное — с открытым ключом для шифрования и закрытым для расшифровки. Шифрование обеспечивает конфиденциальность, целостность и подтверждение подлинности данных. Взлом возможен с помощью перебора ключей (brute force) или анализа слабых мест в алгоритме (криптоанализ). Чем длиннее ключ, тем сложнее взлом. Эти три метода — брандмауэр, антивирус и шифрование — вместе помогают надежно защищать систему от онлайн-угроз.
