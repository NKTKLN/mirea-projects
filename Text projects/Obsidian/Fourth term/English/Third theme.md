## English Version

Computers do not understand natural languages, so programming languages are used to communicate with them. The lowest level is machine code, which consists of 0s and 1s, but it is too complex for programmers to write directly. Assembly languages were introduced to simplify this process by using symbolic commands like ADD and SUB. However, these languages are still difficult to use and depend on specific hardware.

To make programming easier, high-level languages were developed. FORTRAN, created in the 1950s, was designed for scientific calculations. BASIC, introduced in the 1960s, was a simple language for beginners. Pascal became widely used in the 1970s for teaching programming. C and C++ provided both flexibility and control, while Java, developed in 1995, made cross-platform applications possible. Python, introduced in 1989, gained popularity due to its readability and simplicity.

Modern programming often uses object-oriented programming (OOP). Its main principles are encapsulation, inheritance, and polymorphism. Encapsulation bundles data and functions into objects. Inheritance allows new objects to inherit properties from existing ones. Polymorphism enables different objects to respond differently to the same command. These principles make code reusable and efficient, reducing development time. OOP is widely used for multimedia applications, integrating text, graphics, sound, and video seamlessly. By combining modularity and reusability, OOP has become an essential programming paradigm, allowing developers to build complex applications more easily.

## Russian Version

Компьютеры не понимают естественные языки, поэтому для общения с ними используются языки программирования. Самый низкий уровень – это машинный код, который состоит из 0 и 1, но он слишком сложен для написания вручную. Чтобы упростить этот процесс, были созданы языки ассемблера, использующие символические команды, такие как ADD и SUB. Однако эти языки все еще трудно использовать, и они зависят от конкретного оборудования.

Чтобы облегчить программирование, были разработаны языки высокого уровня. FORTRAN, созданный в 1950-х годах, предназначался для научных вычислений. BASIC, появившийся в 1960-х, был простым языком для начинающих. Pascal стал широко использоваться в 1970-х годах для обучения программированию. C и C++ обеспечили гибкость и контроль, а Java, разработанный в 1995 году, сделал возможным создание кроссплатформенных приложений. Python, представленный в 1989 году, приобрел популярность благодаря своей читаемости и простоте.

Современное программирование часто использует объектно-ориентированный подход (OOP). Его основные принципы – инкапсуляция, наследование и полиморфизм. Инкапсуляция объединяет данные и функции в объекты. Наследование позволяет новым объектам использовать свойства существующих. Полиморфизм позволяет разным объектам по-разному реагировать на одну и ту же команду. Эти принципы делают код удобным и эффективным, сокращая время разработки. OOP широко используется в мультимедийных приложениях, объединяя текст, графику, звук и видео. Благодаря модульности и повторному использованию кода, OOP стал важной парадигмой программирования, позволяя разработчикам легче создавать сложные приложения.
